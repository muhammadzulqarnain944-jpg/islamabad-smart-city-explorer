# Islamabad Smart City Explorer

An interactive Web GIS application for exploring
public facilities in Islamabad, Pakistan.

## About the Project

Islamabad Smart City Explorer is a GIS-based web
application that allows users to explore public
facilities through an interactive map.

## Features

- Interactive Leaflet map
- Islamabad administrative boundary
- Education facility mapping
- Healthcare facility mapping
- Public safety facility mapping
- Recreation facility mapping
- Facility search
- Category-based filtering
- Interactive map popups
- PostgreSQL/PostGIS spatial database
- FastAPI backend

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- PostGIS
- SQLAlchemy
- Leaflet.js
- HTML
- CSS
- JavaScript
- QGIS
